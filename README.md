# FX速報 AI

ドル円の速報ニュース・要人発言・経済指標・通貨強弱・チャート・X投稿をまとめて見られる個人向けダッシュボード。
スマホのホーム画面に追加すると、アプリのように使えます（PWA）。

## 主な機能
- 速報ピックアップ／次の重要指標（カウントダウン付き）／まとめて検索
- 速報ニュース（重要度・情報源・ドル円への影響で絞り込み、あとで読むに保存）
- 要人発言、経済指標（リスト／ボード表示）、通貨強弱、チャート（通貨ペア切替）、X投稿
- ライト／ダーク／自動のテーマ切り替え

## ファイル
- `index.html` … 画面
- `assets/app.css` … デザイン（色はすべて先頭のトークンで管理）
- `assets/app.js` … 動作
- `manifest.webmanifest`, `sw.js`, `icons/` … アプリ化（ホーム画面に追加）
- `scripts/fetch_news.py` + `.github/workflows/fetch-news.yml` … 15分ごとに公式RSSを取得してSupabaseへ保存

個人向けの情報整理用です。重要度や影響は見出しのキーワードによる目安で、売買推奨ではありません。
